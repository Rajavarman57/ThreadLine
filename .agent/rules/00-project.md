# 00 - Project: Threadline

Threadline is the operations platform for Everest Textile Mills: raw material and procurement, orders, production floor, quality control, dispatch, invoicing, workforce and costing. It runs live on Vercel with a Neon PostgreSQL database and must stay reliable and quick for many staff and buyers using it at the same time, using serverless resources efficiently. Stack: Next.js 15 App Router, TypeScript strict, Prisma 6 + Neon PostgreSQL (pooled), Auth.js v5 credentials with JWT sessions, Tailwind + shadcn/ui, Zod, React Hook Form, SWR, Recharts, Vitest. Chain: Supplier -> YarnLot -> Order -> WorkOrder (spinning/weaving/dyeing) on Machine -> Roll -> QCInspection -> Dispatch -> Invoice -> Payment. Roles: ADMIN, STORE, SUPERVISOR, QC, ACCOUNTS, BUYER. The agent must NEVER run git commit or git push; the human commits.
